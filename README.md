# MyWireGuardVPN

Android WireGuard client with Connect/Disconnect, saved configuration and connection timer.

## Build
Open in Android Studio, sync Gradle, then Build > Make Project.

GitHub Actions also builds a debug APK automatically on push. Download it from:
Actions -> Build APK -> Artifacts.

## VPS configuration
Paste the contents of `/root/android-vpn.conf` generated by your WireGuard VPS setup into the app and press SAVE CONFIG, then CONNECT.

## Security
Never commit `android-vpn.conf`, private keys, keystores, or passwords. This repository intentionally contains no real VPN credentials.

## Reference
The project uses WireGuard's Android tunnel library. See the official WireGuard Android repository:
https://github.com/WireGuard/wireguard-android
